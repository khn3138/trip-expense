# 출장 경비 (Trip Expense)

출장 기간 동안 쓴 돈을 폰으로 빠르게 기록하고, **회사 일비 기준으로 남았는지/초과했는지** 확인하는 간단한 웹앱(PWA).
엑셀 대신 폰 홈 화면에 추가해서 앱처럼 쓰는 것을 목표로 한다.

## 화면

| 탭 | 내용 |
|----|------|
| **입력** (첫 화면) | 카테고리 버튼 → 금액 → 결제 방식 버튼 → (현금 $면 거스름 리엘) → 메모(선택) → 저장. 상단에 오늘 사용액·일비 대비·누적 남음/초과와 지갑 잔액, 아래에 선택한 날짜의 기록 |
| **내역** | 날짜별 기록, 일 합계($/₩)와 일비 대비 +/−. 탭하면 수정(날짜·카테고리·금액·결제·메모·환율)/삭제 |
| **지갑** | 현금 $ / 현금 ៛ / 카드 $ 잔액과 합계. 넣기(환전·충전), 바꾸기(달러→리엘 등), 맞추기(실제 금액으로 보정), 지갑 기록 |
| **요약** | 총 사용, 하루 평균, 오늘까지 일비 대비, 선지급 대비 잔액, 남은 기간 하루 가용액, 카테고리별·결제 방식별 합계, 전체 예상 |
| **설정** | 출장 기간, 일비, 월별 지급 환율, 카테고리 편집, CSV/백업 |

- 상단 오른쪽 **환율 표시**를 누르면 환율 자동 조회 켜기/끄기와 내 환율(미리 환전한 환율) 입력.
- 날짜는 입력 화면의 날짜 버튼을 눌러 바꿀 수 있다. 오늘이 아닌 날짜면 주황색으로 표시된다.

## 결제 방식

| 버튼 | 결제수단 | 통화 | 용도 |
|------|----------|------|------|
| 현금 $ | 현금 | USD | 미리 환전한 달러 현금 |
| 현금 ៛ | 현금 | KHR | 거스름돈 등으로 받은 리엘 |
| 카드 $ | 카드 | USD | 미리 환전(충전)한 카드 |
| 입금 ₩ | 입금 | KRW | 동료에게 n빵 계좌이체 |

거스름돈을 리엘로 받는 경우: 낸 금액($20)을 적고 **'+ 거스름 리엘 받음'** 에 받은 리엘(10,000៛)을 적는다. 사용액은 그만큼 빠지고 리엘 지갑에 더해진다. 그 리엘로 나중에 쓴 돈은 '현금 ៛'로 기록한다.

카테고리 기본값: 식사, 술, 마트, 카페, 배달, 교통, 생활용품, 팁, 기타 (설정에서 편집)

## 지갑

| 기능 | 설명 | 지출 계산 |
|------|------|-----------|
| 지출 저장 | 결제 방식에 맞는 지갑에서 자동 차감 (입금 ₩은 한국 계좌라 제외) | 포함 |
| 넣기 | 환전, ATM 인출, 카드 충전 등 | 제외 |
| 바꾸기 | 지갑 간 이동 (달러→리엘 등). 받은 금액을 비우면 오늘 환율로 계산 | 제외 |
| 맞추기 | 실제로 센 금액으로 보정. 처음 한 번은 '시작 잔액' | 제외 |

처음 쓸 때는 지금 가진 돈을 세어서 **맞추기**로 시작한다.

## 환율

- **자동 조회 켜짐(기본)**: 하루 한 번 [open.er-api.com](https://open.er-api.com)(무료, 키 불필요)에서 원/달러·리엘/달러 조회. 실패하면 내 환율 → 기본값(1330, 4000) 순으로 사용.
- **자동 조회 꺼짐**: 내 환율(미리 환전한 환율)로만 계산.
- 기록을 저장할 때 그 시점 환율을 기록에 함께 저장 → 나중에 환율이 바뀌어도 과거 기록 금액은 변하지 않는다.
- **회사 지급 환율(월별)** 은 별도: 받은 일비를 원화로 계산할 때만 사용.

## 계산 규칙

| 항목 | 계산 |
|------|------|
| 한 건의 달러 환산 | 달러 − 거스름리엘 ÷ 기록의 리엘환율 / 리엘 ÷ 기록의 리엘환율 / 원화 ÷ 기록의 원환율 |
| 한 건의 원화 환산 | 달러환산 × 기록의 원환율 (원화 입금은 그대로) |
| 경과일 | 시작일 ~ min(오늘, 종료일), 시작일 포함 |
| 오늘까지 일비 누적 | 경과일 × 일비 (원화는 월별 지급 환율) |
| 선지급액 | 지급일(첫 달은 시작일, 이후 매월 1일)이 지난 달의 (그 달 출장일수 × 일비) |
| 하루 평균 | 총 사용 ÷ 경과일 |
| 지갑 잔액 | 넣기 + 바꾸기(받음) − 바꾸기(냄) + 보정 − 지출 (+ 거스름 리엘) |

```
sw.js                 서비스 워커 (앱 파일 오프라인 캐시)
icon.svg              앱 아이콘
```

## 데이터 저장

- 브라우저 `localStorage` (키: `tripExpense.v2`, 예전 `tripExpense.v1`은 자동 변환)에 저장. 서버 없음.
- 폰/브라우저를 바꾸거나 사이트 데이터를 지우면 사라지므로 설정 탭에서 주기적으로 JSON 백업 권장.

## 실행 / 배포

- 로컬: `python -m http.server 8080` 후 `http://localhost:8080`
- 배포: GitHub Pages — **https://khn3138.github.io/trip-expense/** (`main`에 push하면 자동 반영)
- 폰 브라우저에서 위 주소를 열고 **홈 화면에 추가**
