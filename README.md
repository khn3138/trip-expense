# 해외지갑 (Trip Expense)

출장·여행 기간 동안 쓴 돈을 폰으로 빠르게 기록하고, **회사 일비(여행이면 하루 예산) 기준으로 남았는지/초과했는지** 확인하는 간단한 웹앱(PWA).
엑셀 대신 폰 홈 화면에 추가해서 앱처럼 쓰는 것을 목표로 한다. 나라·통화를 설정해서 캄보디아, 일본 등 어디서든 쓸 수 있고, 출장·여행을 여러 개 만들어 따로 관리한다.

## 화면

| 탭 | 내용 |
|----|------|
| **입력** (첫 화면) | 카테고리 버튼 → 금액 → 결제 버튼 → (거스름) → 메모(선택) → 저장. 상단에 오늘 사용액·일비 대비·누적 남음/초과와 지갑 잔액, 아래에 선택한 날짜의 기록 |
| **내역** | 날짜별 기록, 일 합계와 일비 대비 +/−. 탭하면 수정(날짜·카테고리·금액·결제·거스름·메모·환율)/삭제 |
| **지갑** | 현금·카드 결제 버튼마다 잔액과 합계. 넣기(환전·충전), 바꾸기(통화 간 이동), 맞추기(실제 금액으로 보정), 지갑 기록 |
| **요약** | 총 사용, 하루 평균, 오늘까지 일비 대비, 선지급 대비 잔액, 남은 기간 하루 가용액, 카테고리별·결제 방식별 합계, 전체 예상 |
| **설정** | 출장 기간, 일비, 나라·통화(프리셋, 일비 통화, 결제 버튼), 월별 지급 환율, 카테고리 편집, CSV/백업 |

- 상단 왼쪽 **제목**을 누르면 출장·여행 목록이 열린다 (바꾸기, 새로 만들기).
- 상단 오른쪽 **환율 표시**를 누르면 통화별 환율을 보고 📌 고정할 수 있다.
- 날짜는 입력 화면의 날짜 버튼을 눌러 바꿀 수 있다. 오늘이 아닌 날짜면 주황색으로 표시된다.

## 출장 · 여행 여러 개

- 기록·지갑·설정(나라, 결제 버튼, 환율, 카테고리)은 출장·여행마다 따로 저장된다. 자동 환율만 공통.
- **새로 만들기**: 종류, 이름, 나라, 기간, 하루 일비·예산과 통화. 카테고리는 지금 것을 가져온다.
- **종류**

| 종류 | 기준 | 화면 |
|------|------|------|
| 💼 출장 | 회사 일비 (매월 1일 선지급) | 일비 대비, 선지급 대비 잔액, 월별 지급표·지급 환율 |
| 🧳 여행 | 하루 예산 | 예산 대비, 남은 기간 하루 가용액 (선지급·지급 환율 없음) |

- 지금 보고 있는 출장·여행은 설정 탭 아래에서 삭제할 수 있다 (2개 이상일 때).

## 나라 · 통화

설정 탭 **나라 · 통화**에서 고른다.

| 프리셋 | 결제 버튼 | 고정 환율 |
|--------|-----------|-----------|
| 캄보디아 | 현금 $ · 현금 ៛ · 카드 $ · 입금 ₩ | 1$ = 4,000៛ |
| 일본 | 현금 ¥ · 카드 ¥ · 입금 ₩ | - |
| 베트남 | 현금 ₫ · 현금 $ · 카드 ₫ · 입금 ₩ | - |
| 태국 | 현금 ฿ · 카드 ฿ · 입금 ₩ | - |

- **결제 버튼** = 결제수단(현금/카드/입금) × 통화. 프리셋 뒤에 직접 추가·삭제할 수 있다 (예: 원화 신용카드 → 카드 ₩).
- **일비 통화**: 일비와 모든 합계를 이 통화로 보여준다 (USD, JPY 등). 기록이 있으면 바꿀 수 없다.
- 지원 통화: USD, KRW, KHR, JPY, VND, THB, PHP, CNY, TWD, SGD, MYR, IDR, EUR
- 프리셋을 바꿔도 이미 적은 기록과 지갑 기록은 그대로 남는다.

## 거스름

**낸 통화와 다른 통화 현금으로 거스름을 받을 때만** 적는다 (예: $20 내고 10,000៛ 받음). 현금 통화가 2개 이상일 때 현금 결제에 **'+ 거스름 받음'** 이 나오고, 받은 통화를 고를 수 있다.
사용액은 그만큼 빠지고 받은 통화 현금 지갑에 더해진다. 같은 통화로 거스름을 받으면(일본에서 엔으로 내고 엔으로 받기) 실제로 쓴 금액만 적으면 된다.

**n빵 계산기**: 입력 화면의 '÷ n빵 계산'에서 총액과 인원(나 포함)을 넣으면 내 몫이 금액 칸에 들어간다. 통화마다 올림 단위(원화 1/100/1,000원, 엔화 ¥1/¥10/¥100 등)를 고를 수 있고, 기록에는 '(n빵 ₩34,000÷3)'으로 표시된다.

카테고리 기본값: 식사, 술, 마트, 카페, 배달, 교통, 생활용품, 팁, 기타 (설정에서 편집)

## 지갑

| 기능 | 설명 | 지출 계산 |
|------|------|-----------|
| 지출 저장 | 결제 버튼에 맞는 지갑에서 자동 차감 (입금은 한국 계좌라 제외) | 포함 |
| 넣기 | 환전, ATM 인출, 카드 충전 등 | 제외 |
| 바꾸기 | 지갑 간 이동 (달러→리엘 등). 받은 금액을 비우면 오늘 환율로 계산 | 제외 |
| 맞추기 | 실제로 센 금액으로 보정. 처음 한 번은 '시작 잔액' | 제외 |

처음 쓸 때는 지금 가진 돈을 세어서 **맞추기**로 시작한다.

지출을 저장할 때 지갑 잔액이 마이너스가 되면 알림이 뜬다. 현금이 부족하면 다른 통화 현금 결제 중 거스름이 비어 있는 최근 기록을 보여주고, 눌러서 빠진 거스름을 바로 추가할 수 있다. 지갑 탭에도 마이너스 안내가 표시된다.

## 환율

- 모든 환율은 **일비 통화 1단위당** 금액이다 (예: $1 = ₩1,327, $1 = 4,000៛, ¥1 = ₩8.39).
- **자동(기본)**: 하루 한 번 [open.er-api.com](https://open.er-api.com)(무료, 키 불필요)에서 조회. 받기 전에는 내장 임시 환율을 쓴다.
- **📌 고정**: 통화마다 직접 입력한 값으로만 계산 (미리 환전한 환율, 캄보디아 가게 환율 1$ = 4,000៛ 등).
- 기록을 저장할 때 그 시점 환율을 기록에 함께 저장 → 나중에 환율이 바뀌어도 과거 기록 금액은 변하지 않는다.
- **회사 지급 환율(월별)** 은 별도: 받은 일비를 원화로 계산할 때만 사용.

## 계산 규칙

| 항목 | 계산 |
|------|------|
| 한 건의 일비 통화 환산 | 금액 ÷ 기록의 (그 통화 환율) − 거스름 ÷ 기록의 (거스름 통화 환율) |
| 한 건의 원화 환산 | 일비 통화 환산 × 기록의 원 환율 (원화 입금은 그대로) |
| 경과일 | 시작일 ~ min(오늘, 종료일), 시작일 포함 |
| 오늘까지 일비 누적 | 경과일 × 일비 (원화는 월별 지급 환율) |
| 선지급액 | 지급일(첫 달은 시작일, 이후 매월 1일)이 지난 달의 (그 달 출장일수 × 일비) |
| 하루 평균 | 총 사용 ÷ 경과일 |
| 지갑 잔액 | 넣기 + 바꾸기(받음) − 바꾸기(냄) + 보정 − 지출 (+ 거스름) |

## 데이터 저장

- 브라우저 `localStorage` (키: `tripExpense.v4`, 예전 `v3`·`v2`·`v1`은 첫 번째 출장으로 자동 변환)에 저장. 서버 없음.
- 폰/브라우저를 바꾸거나 사이트 데이터를 지우면 사라지므로 설정 탭에서 주기적으로 JSON 백업 권장.
- 백업 파일에는 모든 출장·여행이 들어간다. 예전 백업(출장 하나)을 불러오면 새 출장으로 추가된다.
